# Online Exam System

The Online Exam System is a web-based application designed to conduct online examinations efficiently and securely. It allows students to attend exams online, answer multiple-choice questions (MCQs), and view their results. The system aims to simplify the examination process through a user-friendly interface and digital assessment features.

### Features
- Student login and authentication
- Online examination with MCQ questions
- Randomized questions for assessments
- Automatic result calculation
- Exam timer and submission functionality
- Responsive user interface
- Planned features: OTP verification, fullscreen monitoring, and AI-based cheating detection

### Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Django
- **Database:** MySQL

### Objective
To provide a convenient, efficient, and reliable platform for conducting online examinations and evaluating student performance.
